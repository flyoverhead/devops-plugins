# Changelog

## 2026-11-11

### Added

- Skill `regression-hunt`: coordinates a regression campaign on a GitHub PR (read with `gh pr view --comments`), a commit or a commit range. Detects the host from `git remote get-url origin` and falls back to the commit range once when `gh` or GitHub is unavailable; shows a plan and runs project code only after a yes that explicitly allows it; freezes `scope.json`, copies the target's instruction files from git objects, and dispatches every stage to a fresh background `general-purpose` agent with a launch-record and handle-file handshake.
- Stage skills `prepare-regression` (S0/S1 pinning rules for commits, ranges, open, merged, squashed and rebased PRs; frozen context; exports), `hunt-regressions` (candidate files with stable hypothesis keys, no PoCs), `reproduce-regression` and `replay-regression` (one PoC against live S0 and S1 builds in the attempt's own directory; replay rebuilds independently with the byte-identical PoC), `adjudicate-regression` (six outcomes, nine cited checks for a confirmation, severity and likelihood) and `report-regressions`.
- Scripts (Python 3 standard library, no project or dependencies): `registry.py` (version 3 attempt registry: `init`, `reserve`, `bind`, `candidate`, `retry`, `check`, `accept`, `show`, file lock and atomic writes), `evidence.py` (`seal`, `verify` with recursive dependencies), `snapshot.py` (git archive exports of S0 and S1 with patch, messages and `source.json`; refuses submodules, LFS pointers, export attributes and unsafe archive entries), `report.py` (`index.html`, `report.md`, `report.json`; integrity failures write nothing, invalid decisions show as UNRESOLVED), `runtime.py` (launch and terminal records, handle publishing, the worker's wait) and `guidance.py`.
- Snapshot safety: refuses trees whose paths collide after case folding and NFC normalisation, paths below a symlink, symlinks leaving the tree (all symlinks when the Python has no tar extraction filter), and any export whose file list differs from `git ls-tree -r` (catches `export-ignore` set in `.git/info/attributes`); archive errors are refusals, and the patch is taken with `--no-ext-diff --no-textconv`. Evidence seals hash symlinks that stay inside their listed directory by link text and refuse escaping ones, so snapshots and build directories with internal symlinks can be sealed.
- Handshake checks: `runtime.py launch` needs the launch text's `output_file` to be named `<agent id>.output` and to exist (only the name is checked when a sandbox denies access to the task directory); `runtime.py terminal` refuses a task id other than the agent launched for the attempt; `registry.py accept` needs that attempt's completed or failed terminal record. `registry.py retry` also recovers reserved attempts (never launched, or launched with a failed bind once the stray agent's terminal record exists) and accepted attempts whose record is blocked, keeping the hunt prefix so a reused hypothesis key gets the same candidate id.
- Script messages are worded independently of any other implementation on purpose (`evidence.py <action> refused: …`, `registry.py <command> refused: …`, `snapshot.py: …`).
- This version records only the `shared-host` verification level: host-observation records (`isolated`) and non-Claude agent recognisers are documented in the record formats but not produced.
- Tests: pytest suites per script and an end-to-end campaign; `tests/run-all.sh`.
- Evals: a before/after trigger, a read-only review negative, an approval gate, and `outcome-go-auth-regression`, a remote-less Go CLI whose second commit lets an empty operator key through, reported as a confirmed regression on the commit range.
- Every documented `git diff`, `git show` and patch-showing `git log` passes `--no-ext-diff --no-textconv`.
